# Smart Money Concepts Trading System

🚧 **Project Status: Active Development (Work in Progress)**

## Overview

This repository contains a Python-based algorithmic trading system designed for financial market analysis using Smart Money Concepts (SMC).

The project aims to provide a modular framework for identifying market structure, detecting trading opportunities, visualizing market behavior, and recording trading activity. Development is ongoing, and new analytical methods and trading functionalities are continuously integrated based on research findings and project evolution.

---

## Features

Current capabilities include:

- Exponential Moving Average (EMA)
- Average True Range (ATR)
- Swing High / Swing Low Detection
- Support and Resistance Zone Detection
- Trend Detection
- Break of Structure (BOS)
- Change of Character (CHoCH)
- Trade Signal Generation
- Trade Visualization
- Export Trade History to Excel
